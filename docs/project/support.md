## Issue tracker

[GitHub Issues](https://github.com/eddiethedean/pydantable/issues) — bugs, feature requests, documentation gaps.

Include Python version, **`pydantable.__version__`**, and whether the native extension loaded (see [Installation](../getting-started/installation.md#verify-your-install)).

## Release cadence

- **1.x** semver: patches for fixes, minors for additive APIs
- Release history: [Changelog](changelog.md)
- Forward work: [Roadmap](roadmap.md)

## Commercial support

There is **no** official commercial support SLA from the open-source maintainers. Enterprise adopters should plan internal ownership or third-party support.
